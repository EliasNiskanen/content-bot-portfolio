# 05 YouTube Studio

## Päivittäinen tarkistus (5–10 min, kun lataukset ovat yksityisiä)

1. **Katso video** (tai ainakin alku, pari kohtaa keskeltä ja loppu). Tarkista faktat lähteistä, jos jokin
   kuulostaa oudolta.
2. **Thumbnailit:** avaa `data\output\*_thumbs_compare.jpg`. Lukeeko teksti pienessäkin koossa?
3. **Thumbnail → Test & compare:** lisää kaikki 3 thumbnailia (API ei osaa tätä).
4. **Loppuruutu:** Studio → video → End screen → aseta Subscribe-elementti logoympyrän päälle ja kaksi
   videoelementtiä kehyksiin (`assets\brand\endscreen_template.png`).
5. **Mainokset:** yli 8 min videoissa mid-roll-mainokset (Monetization → Ad breaks) kun kanava on
   monetisoitu.
6. **Shortsit:** lisää jokaiseen **Related video** -linkki pitkään videoon.
7. **Julkaise** (tai jätä ajastus, kun `auto_publish` on päällä).

## Kanavan asetukset (kerran)

| Asia | Mistä |
|---|---|
| Kanavan kuvaus | `assets\brand\channel_description.txt` → Customization → Basic info |
| Vesileima | `assets\brand\watermark_150.png` → Customization → Branding → Video watermark |
| Banneri ja logo | `assets\brand\banner.png`, `assets\brand\logo.png` |
| Puhelinvahvistus | youtube.com/verify (thumbnailien asettaminen) |

## Content ID -vaatimukset

Audio Libraryn musiikki ei aiheuta vaatimuksia. Rockstarin trailerikuva voi aiheuttaa. Vaatimus ei ole
varoitus (strike) eikä vaikuta kanavan asemaan, mutta voi ohjata videon tulot vaatijalle. Riitautus: Studio →
Content → See details → Dispute → perustele lyhyellä kommentoivalla uutiskäytöllä.

## Monetisoinnin vaatimukset (YouTube Partner Program)

- 1 000 tilaajaa ja 4 000 katselutuntia 12 kuukaudessa (pitkät videot), tai Shorts-polku.
- Ei massatuotettua toistuvaa sisältöä: jokainen video on oma käsikirjoitus omalla näkökulmalla ja lähteillä.
- AI-ääni on merkitty (`containsSyntheticMedia`) ja mainittu kuvauksessa.
